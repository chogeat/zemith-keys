제미스 키스 (Zemith Keys) v2.3 - 설치형 앱 파일

[GitHub Pages에 올리는 방법]
1. https://github.com 에서 무료로 가입해요.
2. 오른쪽 위 + 버튼 > New repository
   - Repository name: zemith-keys
   - Public 선택 > Create repository
3. 다음 화면에서 "uploading an existing file" 글자를 눌러요.
4. 이 zip을 푼 파일 7개(index.html, sw.js, manifest.webmanifest, icon-192.png, icon-512.png, icon-maskable-512.png, README.txt)를
   끌어다 놓고, 아래 초록색 "Commit changes"를 눌러요.
5. 저장소 위쪽 Settings > 왼쪽 메뉴 Pages
   - Source: Deploy from a branch
   - Branch: main, 폴더 / (root) > Save
6. 1~2분 뒤 Pages 화면 위쪽에 주소가 나와요.
   예) https://아이디.github.io/zemith-keys/
7. 휴대폰 크롬으로 그 주소를 열고, 메뉴(⋮) > "앱 설치"(또는 "홈 화면에 추가")를 눌러요.

[업데이트할 때]
새 파일을 받으면 같은 저장소에서 Add file > Upload files로 다시 올리고 Commit changes를 누르면 돼요.
앱은 인터넷이 연결된 상태로 열 때 새 버전을 받아서, 다음에 열 때 적용돼요.

[참고]
- 곡 파일(MR, 원곡, 드럼)은 이 저장소에 올리지 않아요. 각자 휴대폰에서 앱에 직접 넣어요.
- 주소를 아는 사람은 누구나 앱을 열 수 있어요(가입 필요 없음).
